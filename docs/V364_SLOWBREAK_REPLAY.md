## 结论（只报证据，不做收益主张）

1. NEW 口径在本区间触发 **0** 次；OLD 口径同样 0 次 ⇒ **决策数值零差异**：
   Δtarget 最大 0pp、action 变化 0 次、EXIT/STRATEGIC_REDUCE/TACTICAL_REDUCE 全部 +0。
2. 零触发的**原因已被定位**（不是机制坏了）：该区间内 5 只 ETF 的 `SlowBreak` 分数只出现过 0 / 20 / 50，
   从未出现 ≥75（见上方「触发条件逼近度」表）。
3. 而 `SB>=75` 达不到的根因是**快照字段缺失**（见上一节 ★）——
   这是比缺陷 #2 更底层的问题，R1 未修、本轮也不修（属策略级变更）。
4. 因此本 Gate 证明的是**上游安全性**：「R1 的 SlowBreak 改动在生产数据上零副作用」。
   它**不能**证明「触发时机正确」—— 那需要先补齐快照字段再重跑本 Gate。
5. 建议：把「补齐 `ma60_slope` / `high_point_falling`(或 `lower_high`) 快照字段」单独立项；
   立项前不要启用任何依赖 SlowBreak 的加/减仓语义。
