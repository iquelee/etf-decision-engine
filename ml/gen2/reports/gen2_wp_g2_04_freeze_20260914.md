## 3. 离线迁移：语义等价，不是调参

换算与 JS `deriveRoleThresholdsFromLegacy()` **逐式一致**：

```
core_top_fraction       = 1 - top_quantile          = 1 - 0.2  = 0.20
challenger_top_fraction = 1 - challenger_pct        = 1 - 0.7  = 0.30
satellite_top_fraction  = 1 - satellite_pct         = 1 - 0.6  = 0.40
（四舍五入到 1e-10，避免 1-(1-0.2)=0.19999999999999996 落进 bundle）
```

派生切点仍是 `core_pct 0.80 / challenger 0.70 / satellite 0.60` ⇒ **与迁移前后行为完全一致**。

旧字段**不删除**，移入 `selection.legacy_migration_audit`（`status = MIGRATION_AUDIT_ONLY`）留痕；
运行路径（Node `resolveRoleThresholds()` / Python `load_role_thresholds()`）只读 `role_thresholds`。
`--check` 与两个新测试都会**拒绝旧字段残留在运行段**。

### 4.0 为什么把 `role_thresholds.py` 也钉住（审查裁决 2026-09-14）

| 问题 | 说明 |
|---|---|
| 旁路形态 | 该模块定义**线上阈值从哪里读、读到什么算合法**（`load_role_thresholds` / `validate_role_thresholds` / `DEFAULT_ROLE_THRESHOLDS` / `ROLE_THRESHOLD_FIELDS`）。不锁定它，就能在 **bundle 字节完全不变** 的前提下改掉阈值来源、合法键集合或默认兜底 → 「bundle 未变、运行语义已变」 |
| 处理 | 追加进 `immutable_set`（`python_role_thresholds`），`lock_revision 1 → 2`，同步 `ROOT_ANCHORS` |
| 同时钉住的两件事实 | ① 条目数 5 → 6 与 **id 必需集合** 都进 `verify-immutable.js`（防「少条目/被顶替也算 PASS」）；<br>② `test_wp_g2_04_freeze.py::test_frozen_role_thresholds_file_is_the_module_runtime_imports` 断言**被锁的文件 == 运行时 import 的模块路径**（防「锁 A 读 B」） |
| 刻意**不**入锁 | `scripts/ml/freeze-gen2-rule-bundle.py` —— 它不是运行时依赖，只在冻结时人工执行（§10 的「临时验真」入口）。锁住它没有安全增益，只会让每次改脚本都要再封印 |

扩围留痕写入 `lock.lock_amendments`（含 `bundle_bytes_changed: false` / `bundle_version_changed: false`），
避免以后被误读成「改过规则」。

### 4.1 冻结的代价（需要知情）

自本次起，**修改上述任一实现文件都会让 `verify-immutable.js` FAIL**。合法路径是显式再封印：

```
新 bundle_version + 重新生成 lock + 同步 verify-immutable.js 的 ROOT_ANCHORS
```

`ml/gen2/tests/test_wp_g2_04_freeze.py::test_lock_root_anchor_in_verifier_is_in_sync` 会在
**Stage B** 就抓出「忘了同步 ROOT_ANCHORS」，不必等到 Stage C。

## 5. 两个「冻结会顺带打脸」的回归点（已处理）

冻结不是只改数据，它会让**依赖「bundle 恰好还没迁移」的回归**失真。已逐条处理：

| 位置 | 风险 | 处理 |
|---|---|---|
| `ml/gen2/tests/test_selection_scores.py::RuleBundleGateTest` | 用 `manifest["selection"]` 当基线，冻结后基线自带 `role_thresholds` ⇒ 4 条「缺配置 → blocked」变成假红 | 新增 `_cfg_missing()` **显式剥掉** `role_thresholds`，让「缺配置」是**构造出来的**，不依赖 bundle 状态 |
| `fixtures/gen2/golden_scenarios_v1.json` G2S-09 | `bundle_selection_base_source` 声称镜像冻结 bundle ⇒ 冻结后**变成谎话** | 改标为 `SYNTHETIC`，并说明「刻意不镜像冻结 bundle」；冻结后 bundle 是否过闸门改由新增测试直接断言真实 bundle |

> `bundle_selection_base` 的**值**故意保持旧形态 —— 它是闸门回归的输入，不是冻结 bundle 的镜像。
> 这正是「夹具不能自证」的一个具体形态：夹具照 seam 期望形状手写，就发现不了消费方接线问题。
