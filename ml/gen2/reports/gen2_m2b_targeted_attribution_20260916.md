## §1 方法：什么是「会计式分解」，它为什么必须严格闭合

`C→D` 这一层在 M2 里是**混装**的：它同时包含「单只上限截断」「cluster 上限缩权」「广义科技上限缩权」三种机制，以及三者各自产生的残差现金。M2-B 把它拆成两段，拆法**完全照抄冻结实现的执行顺序**：

```text
relative_share = 1 / |CORE|                    ← C 层（每日 CORE 等权，Σ证券 = 1，无上限）
步① 单只:  w1 = min(relative_share, 0.25)      ← D1 层（截断；差额留现金）
步② cluster: 同 (日, cluster) 内 Σw1 > 0.40 → 该组整体 × (0.40 / Σw1)
步③ 科技:   同日 tech_clusters 合计 > 0.65 → 仅科技行 × (0.65 / 合计)
                                               ← D2 层 = 步①②③ = gen2_v2_undefended
```

（`ml/gen2/baseline/rule_v2_ab.py` 第 329–365 行，冻结实现，**未改一字**。）

* **`C→D1`** = 只跑步① ⇒ 「单只截断及其新增残差现金」；
* **`D1→D2`** = 跑步②③ ⇒ 「cluster/科技缩权及其新增残差现金」。

**为什么必然闭合**：两段都是**同一个账本函数**（`gen2.backtest.ledger.run_ledger`，同日历、同 T+1、同期初全现金）算出的累计净收益之差：

$$
\underbrace{\big(p_{D1} - p_C\big)}_{\text{C} \to \text{D1}} + \underbrace{\big(p_{D2} - p_{D1}\big)}_{\text{D1} \to \text{D2}} \equiv \big(p_{D2} - p_C\big) = \text{原 C} \to \text{D}
$$

这是**代数恒等**，不是近似。本包实测 `identity_gap_pct = 0.0`（未取整口径），`exact_identity = true`。

**「残差不重新分配」如何保证**：`rule_v2_ab` 的权重流水线**从不归一化**（源码注释：*"剩余留现金（不自动归一化到 100%）"*）。截断与缩权产生的差额**全部留作现金**，没有任何再分配给其他 ETF 的步骤。本包只**读取**该实现，未插入任何再分配逻辑。

**⚠️ 一个容易误读的点**：`C→D1` 的 `−14.83pp` **不是**「持仓不同」造成的 —— `C` 与 `D1` 的**持仓集合完全相同**（都是当日 `role == "CORE"` 的标的）。差异**只在权重**（与随之而来的现金）。这正是「会计式分解」与「策略对比」的区别。

### 3.3 三条硬结论

**① 单只上限才是 `C→D` 的负贡献源，且它实质上是「仓位削减」而非「分散化」。**
单只截断在 OOS **多制造了 17.41pp 的现金**，代价是 **−14.83pp** 收益。它只在 `|CORE| ∈ {1,2,3}` 的日子生效（`1/|CORE| > 0.25`），把仓位从 `1/N` 一刀切到 `0.25`。⇒ **这些「少数标的入选」的日子本来是赚钱的**，被上限削掉了。

**② cluster/科技缩权在 OOS 是 **正贡献**（`+8.02pp`），方向与单只截断**完全相反**。**
它只多制造 3.74pp 现金，却带来 +8.02pp 账本收益。⇒ **被 cluster 上限削掉的那部分权重是不赚钱的**（多留现金反而避开了损失）。**这一条直接证伪了 M2 §6 的 H3 表述**（详 §6.2）。

**③ `D1→D2` 内部：cluster 缩权占绝对主导，科技上限几乎不起作用。**
权重层面的缩权量：**cluster `−51.10`** vs 科技 **`−5.25`** ⇒ cluster 占 **90.7%**、科技占 **9.3%**。这与 M2 §4.2 的绑定读数一致（科技上限 OOS 仅 137/980 日 ≈ 10.0% 被绑定）。
⚠️ 口径说明：该读数**只用于指出 D1→D2 内部成因**，是**权重层面**的统计，**不参与**主分解加总（主分解严格两段）。

### 5.7 三条归因结论

**① 成本拖累的根源是「换手频度」，不是「换手类型」。** 81.1% 的交易日都在调仓、中位间隔 1 天 —— 即便单笔幅度小（活跃日均 0.1196），**累积 6 年就是 133.4 个单边腿、13.34% 费用**。

**② `reweight`（非角色切换的权重调整）是最大单项**（换手 38.15%、成本 5.09%），**不是**「角色进出」。这与 H4 的原始直觉相反。

**③ 换手在被「`CORE==0` 长区段」拉长间隔的同时，反而在「有 CORE 的区段」被高频触发** —— 最长间隔 91 天与中位间隔 1 天并存，说明调仓行为是**双态的**：要么长期不动（整仓现金），要么几乎逐日重排。
