### 1.2 机制解释：**原表述错误**

原 M2 §6 的 H3 行把 `C→D` 的负贡献**主要归因于 cluster 上限**。该解释**方向相反**，其机制前提已被 M2-B §3 的会计式拆分**证伪**。

### 1.3 正确拆分（M2-B §3；`exact_identity = true` / `identity_gap_pct = 0.0`）

| 步 | 层（严格照冻结实现 `rule_v2_ab` 的执行顺序） | Δ |
|---|---|---|
| `C→D1` | **单只截断** `min(1/\|CORE\|, 0.25)` + 其新增残差现金 | **−14.83 pp** |
| `D1→D2` | **`max_cluster_weight = 0.40` / `max_tech_weight = 0.65` 缩权** + 其新增残差现金 | **+8.02 pp** |
| **`C→D`** | **两段加总（恒等）** | **−6.82 pp** |

⇒ **`C→D` 的负贡献来自「单只截断」，不是 cluster 上限** —— cluster/科技缩权在 OOS 实际是**正贡献**。
⇒ `D1→D2` 内部成因：cluster 缩权 Σw `−51.10`（**90.7%**）vs 科技缩权 `−5.25`（9.3%）。
⇒ 残差**全部留作现金**（OOS 残差现金 `C 0.2878 → D1 0.4618 → D2 0.4992`），**未**重新分配给其他 ETF；两段加总**严格闭合**回原 `C→D`。

## §2 为什么原解释会错（**口径原因**，不作动机推断）

1. M2 只做**单层差分** `C→D`，把「单只截断」与「cluster/科技缩权」两个效应**合并成一个净数**；净数（−6.82）由量级更大的**截断效应**主导，缩权效应被其抵消。
2. **单层差分结构上无法区分**两个方向相反的子效应 —— 不做会计式拆分，符号归属就无从判定（这是口径限制，不是数据问题）。
3. M2-B 的拆分严格照冻结实现的权重流水线：`relative_share = 1/|CORE|` → ① 单只 `clip(0.25)` → ② cluster `0.40` 按比例缩 → ③ 科技 `0.65` 按比例缩；**`D2` 权重逐位复现** `gen2_v2_undefended`（`max_abs_diff = 0.000e+00`，3,703 行 CORE）。
